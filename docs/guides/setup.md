# Set up and record your first take

The first time Shotmaxxing opens, setup walks you through five short steps, from the permissions it needs to a
ten-second practice take with its zooms already added.

## The five steps

1. **Welcome.** The logo builds itself; any key or click skips it.
2. **Permissions.** Screen Recording is the only one Shotmaxxing needs. The page checks each permission live, so it
   updates the moment you allow something. See [Permissions](permissions.md).
3. **Connect AI** (optional). Connect Claude Code, Codex or another agent you have, so it can film demos for you.
   You can do this later from **Agents**. See [Agents](../agents.md).
4. **Practice.** Press **Record practice take**, move around and click a few things. You'll see the result with
   zooms already added. Or choose **Skip practice**, and the sample project is ready instead.
5. **Done.** Three things worth remembering:

| Shortcut | What it does |
| --- | --- |
| <kbd>⌥</kbd><kbd>⇧</kbd><kbd>5</kbd> | Record from anywhere |
| <kbd>⌘</kbd><kbd>K</kbd> | Search and run anything |
| <kbd>⌘</kbd><kbd>/</kbd> | See every shortcut |

On Windows, <kbd>⌘</kbd> is <kbd>Ctrl</kbd> and <kbd>⌥</kbd> is <kbd>Alt</kbd>.

## Your first real take

1. Press <kbd>⌥</kbd><kbd>⇧</kbd><kbd>5</kbd>, or choose Record from the Shotmaxxing icon in the menu bar.
2. Choose **Window**, then click the window you want to film.
3. Use the app as you normally would. Shotmaxxing hides the real cursor and draws a smooth one later.
4. Click **Stop** in the recording pill. The editor opens with the zooms already added.

From there, the [editor guide](editor.md) shows every tool, and [Export](export.md) gets the video out.

## Explore the sample project

**Learn** in the sidebar opens a 21-second sign-up demo filmed by an agent. Choose **Open with tour**, and a short
tour shows you every tool, one at a time. Learn also lists short guides for recording, editing, exporting and using
AI, and keeps track of the ones you've done.

## Run setup again

**Settings → Help → Run setup again** starts from the welcome. **Replay the editor tour** sits next to it.
