# The camera bubble

Record your camera with the screen, and you show up in a bubble next to the action. Turn on **Camera** in the record
dialog, then press <kbd>5</kbd> in the editor for the Camera tool.

| Setting | What it does |
| --- | --- |
| Show camera | Shows or hides the bubble |
| Shape | **Circle**, **Rounded** or **Square** |
| Size | How big the bubble is |
| Corner | Which of the four corners it sits in |
| Shrink while zoomed | The bubble gets smaller during zooms, so it never covers the action |
| Mirror | Flips the camera, the way you see yourself in a mirror |

> [!NOTE]
> On a Mac the camera needs the **Camera** permission the first time. See [Permissions](permissions.md).
