# Keyboard shortcuts

Press <kbd>⌘</kbd><kbd>/</kbd> in the app to see these at any time. On Windows, <kbd>⌘</kbd> is <kbd>Ctrl</kbd> and
<kbd>⌥</kbd> is <kbd>Alt</kbd>.

## Anywhere

| Shortcut | What it does |
| --- | --- |
| <kbd>⌥</kbd><kbd>⇧</kbd><kbd>5</kbd> | New recording, or stop the one running |
| <kbd>⌥</kbd><kbd>⇧</kbd><kbd>4</kbd> | Styled screenshot |
| <kbd>⌘</kbd><kbd>K</kbd> | Search and run anything |
| <kbd>⌘</kbd><kbd>/</kbd> | Every shortcut |
| <kbd>⌘</kbd><kbd>,</kbd> | Settings |

## Playback

| Shortcut | What it does |
| --- | --- |
| <kbd>Space</kbd> | Play or pause |
| <kbd>J</kbd> | Back, pause or forward |
| <kbd>←</kbd> <kbd>→</kbd> | One frame back or forward |
| <kbd>Home</kbd> | Go to the start |

## Editing

| Shortcut | What it does |
| --- | --- |
| <kbd>1</kbd> to <kbd>7</kbd> | Open a tool: Background, Cursor, Zoom, Annotate, Camera, Audio, AI |
| <kbd>S</kbd> | Split at the playhead |
| <kbd>Z</kbd> | Add a zoom at the playhead |
| <kbd>⌫</kbd> | Delete what's selected |
| <kbd>⌘</kbd><kbd>Z</kbd> | Undo |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>Z</kbd> | Redo |

## Project

| Shortcut | What it does |
| --- | --- |
| <kbd>⌘</kbd><kbd>E</kbd> | Export |
| <kbd>⌘</kbd><kbd>⌥</kbd><kbd>H</kbd> | Version history |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>T</kbd> | The editor tour |

## During an agent's take

| Shortcut | What it does |
| --- | --- |
| <kbd>Esc</kbd> three times | Stop the take at once. Moving the mouse stops it too |
| <kbd>⌥</kbd><kbd>⌘</kbd><kbd>Return</kbd> | Hand back to the agent after a step it gave you (<kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>Enter</kbd> on Windows) |

**Settings → Shortcuts** lists the main ones too.
