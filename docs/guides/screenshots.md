# Styled screenshots

A full-resolution picture of a screen or a window on a background with a real shadow, framed in the editor and
copied in one step.

## Take one

1. Press <kbd>⌥</kbd><kbd>⇧</kbd><kbd>4</kbd> (<kbd>Alt</kbd><kbd>Shift</kbd><kbd>4</kbd> on Windows). The record dialog
   opens with **Screenshot** chosen.
2. Choose **Screen** or **Window**, and pick what to capture. A window is captured on its own, even if something
   covers it; for a screen, the dialog steps aside first.
3. Press **Take screenshot**, or <kbd>Return</kbd>. The picture opens in the editor.

## Frame it

The editor shows two tools for a screenshot:

- **Background** (<kbd>1</kbd>): a wallpaper, padding, corner radius, shadow, and the shape: **Fit** (the picture's
  own shape), 16:9, 4:3, 1:1 or 9:16. The next screenshot starts with the same look.
- **Annotate** (<kbd>2</kbd>): a title, an arrow or a blur. Pick one to add it, then drag it into place or nudge it
  with the arrow keys.

See [Background](background.md) and [Annotate](annotate.md) for each setting.

## Copy or save it

- <kbd>⌘</kbd><kbd>C</kbd> copies it at full resolution, ready to paste into a chat, a doc or an issue.
- <kbd>⌘</kbd><kbd>E</kbd> saves it as a PNG.

> [!TIP]
> Any frame of a video can be a picture too: in a video's export, choose **This frame as an image**, or run
> `shotmaxxing export <project> --format png --at 12.5`.
